# 01 - Tune: GPU offload (-ngl) — supporting measurement for REFLECTION §5

Not generated by `make tune` (which only sweeps threads). Ran directly with
`llama-bench` on the same primary model, holding threads fixed at 6, to isolate
the effect of `-ngl` after the thread sweep came back flat.

```
runtime/b10488/llama-b10488/llama-bench -m models/Qwen3.5-0.8B-Q4_K_M.gguf -t 6 -ngl 0  -p 0 -n 128 -r 3
runtime/b10488/llama-b10488/llama-bench -m models/Qwen3.5-0.8B-Q4_K_M.gguf -t 6 -ngl 99 -p 0 -n 128 -r 3
```

| ngl | Where decode runs | tg128 (tok/s) |
|--:|---|--:|
| 0  | CPU only (6 threads)                | 57.63 ± 2.19 |
| 99 | Vulkan, offloaded to Intel iGPU      | 187.23 ± 2.11 |

**Speedup: 3.25x** — this is the change that mattered most on this machine, not
thread count. See REFLECTION.md §5 for the mechanism.
